# Security policy

The Game Cellar is a non-commercial game backlog service. If you have found a security problem in it, thank you for taking the time to report it.

## Reporting a vulnerability

Email **hello@gamecellar.app**. Please do not open a public issue or pull request for a security problem.

A useful report says:

- what is affected: a URL, an endpoint, or a repository and file
- the steps that reproduce it
- what an attacker could do with it

English or Swedish, whichever is easier for you.

## What happens next

- You get a reply within 7 days confirming that the report has arrived.
- There is no promised date for a fix. How fast one lands depends on how serious the problem is, and you will hear how it is going.

## Scope

In scope:

- https://gamecellar.app
- https://auth.gamecellar.app
- the public repositories of the [The-Game-Cellar](https://github.com/The-Game-Cellar) organisation

Out of scope:

- denial of service and load testing
- social engineering, phishing and physical attacks
- spam
- bugs in the third-party services the product runs on, such as Cloudflare, Keycloak itself and GitHub: report those to their own vendors

## Good faith

No legal action will be taken against research done in good faith. Good faith means that you:

- use only your own account, or one whose owner has given you permission
- stop as soon as you reach data that is not yours, keep none of it, share none of it, and say in your report that you reached it
- do not degrade the service for anyone else
- give the problem time to be fixed before you make it public
